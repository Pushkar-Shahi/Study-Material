# 🕵️ Unsupervised Learning

> [!NOTE]
> **Definition:** Unsupervised learning is a type of machine learning where a model is trained on **unlabeled data** without any human intervention or predefined categories. Unlike supervised learning, which relies on a teacher or a ground-truth map, unsupervised learning algorithms must discover hidden structures, groupings, and patterns entirely on their own. This approach is highly valuable in the real world because the vast majority of global data is unannotated, and manually labeling datasets is expensive, slow, and prone to human bias.

## 🧠 Core Techniques and Algorithms
Unsupervised machine learning is primarily split into three distinct categories based on the data objective:

### 1. 🗂️ Clustering
This technique divides data points into distinct groups based on feature similarities. Data points within the same cluster share similar traits, while points in different clusters are highly distinct.

- **K-Means Clustering:** Partitions data into `K` number of user-defined clusters by minimizing the distance between data points and the cluster center (centroid).
- **Hierarchical Clustering:** Builds a tree-like structure of clusters (a dendrogram), either by combining small groups (agglomerative) or splitting large ones (divisive).
- **DBSCAN:** Groups points based on how closely packed they are (density), making it highly effective at identifying outliers and working with irregular shapes.

### 2. 📉 Dimensionality Reduction
When data contains too many variables (high-dimensional data), models can become slow, complex, and prone to overfitting. This technique compresses the data by keeping only the most meaningful, information-rich traits.

- **PCA (Principal Component Analysis):** Rotates and projects data onto new perpendicular axes that capture the maximum possible variance using fewer variables.
- **t-SNE / UMAP:** Advanced techniques tailored for visualizing complex, multi-dimensional structures in simple 2D or 3D spaces.

### 3. 🔗 Association Rule Learning
This is a rule-based approach used to uncover frequent "if-then" relationships and co-occurrences between variables within large transactional databases.

- **Apriori Algorithm:** Identifies frequent itemsets in data and extends them to determine general predictive rules.
- **FP-Growth:** A faster alternative to Apriori that compresses the database into a tree structure to mine patterns without heavy computation.

### 🛠️ MLOps Perspective: Unsupervised Learning

> [!IMPORTANT]
> As an aspiring MLOps Engineer, keep these things in mind for Unsupervised Learning pipelines:
> 
> - **Evaluation Challenges:** Since there are no ground-truth labels, evaluating these models in CI/CD pipelines is tricky. Use intrinsic metrics like the Silhouette Score for clustering.
> - **Pipeline Integration:** Unsupervised learning is often a preprocessing step (e.g., PCA before classification, or clustering to generate pseudo-labels). Make sure your MLOps pipeline properly chains these models (e.g., scikit-learn Pipelines).
> - **Anomaly Detection:** Algorithms like DBSCAN or Isolation Forests are heavily used in MLOps for **infrastructure monitoring** and detecting anomalous data drifts or malicious activity.
