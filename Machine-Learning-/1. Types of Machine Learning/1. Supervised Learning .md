# 🎯 Supervised Learning

> [!NOTE]
> **Definition:** Supervised learning is a type of machine learning where an AI model is trained using **labeled data**, meaning every input training example is paired with its correct corresponding output. The model analyzes these input-output pairs to learn the underlying mathematical mapping, adjusting its internal parameters to minimize prediction errors on new, unseen data.

## 🧱 Core Components

- **Features (x):** The independent variables or input data used to make a prediction (e.g., house size, location, age).
- **Labels (y):** The ground truth target or correct "answer" the model tries to learn to predict (e.g., house price).
- **Training Phase:** Feeding the model features and labels so it maps the function `y = f(x)`.
- **Testing Phase:** Evaluating model performance on a separate subset of unseen data to calculate accuracy.

## 🔀 The Two Main Types of Tasks
Supervised learning is fundamentally split into two categories based on the nature of the target label:

| Type | Target Output | Example |
| :--- | :--- | :--- |
| **1. Classification** | Discrete class or category label (Categorical Outputs) | Spam detection (Spam/Not Spam) |
| **2. Regression** | Continuous, numerical value along a spectrum (Continuous Outputs) | House price prediction |

## ⚖️ Advantages and Limitations

> [!TIP]
> **Pros**
> - **High Control:** Clear objective functions make it easy to evaluate how accurate a model is.
> - **Powerful Predictor:** Highly effective for specific corporate tasks like automated data entry or credit scoring.

> [!WARNING]
> **Cons**
> - **Data Bottleneck:** Requires massive amounts of clean, manually-labeled data, which is time-consuming and expensive to generate.
> - **Overfitting Risk:** If trained too long or on too small a sample, the model memorizes the training data perfectly but fails on new data.

---
### 🛠️ MLOps Perspective: Supervised Learning

> [!IMPORTANT]
> As an aspiring MLOps Engineer, keep these things in mind for Supervised Learning pipelines:
> 
> - **Data Versioning:** Labeled datasets are your ground truth. Use tools like DVC (Data Version Control) to version control your labels. If labels change, the model needs retraining.
> - **Model Evaluation & Metrics Tracking:** For Classification, track F1-Score, ROC-AUC, Precision, and Recall. For Regression, track RMSE, MAE. Use tools like MLflow or Weights & Biases to log these.
> - **Concept Drift:** Supervised models are highly susceptible to drift. Monitor if the distribution of incoming features (x) or relationships with targets (y) shift over time in production.
