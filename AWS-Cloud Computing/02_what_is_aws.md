## 🌐 The Basics

**Amazon Web Services (AWS)** is a comprehensive cloud computing platform. Launched as a cloud provider in **2006**, it's now the **world's leading provider**, offering **200+ services** from global data centers.

---

## 🏗️ The Four Core Infrastructure Categories

| Category | Example Services | Purpose |
|---|---|---|
| 💻 **Compute** | EC2 (virtual machines), Lambda (serverless), ECS/EKS (containers) | Run applications and code |
| 💾 **Storage** | S3 (object storage), EBS (block storage), Glacier (archiving) | Store files and data |
| 🗄️ **Databases** | RDS (SQL), DynamoDB (NoSQL), Redshift (data warehousing) | Managed database solutions |
| 🌐 **Networking** | VPC (isolated networks), Route 53 (DNS), CloudFront (CDN) | Connect and secure resources |

---

## 🌍 Global Infrastructure

| Component | Description |
|---|---|
| **Regions** | Geographically distinct locations (e.g., **US-East-1** / Northern Virginia — where most new features launch first) |
| **Availability Zones (AZs)** | Isolated data centers within a region — for high availability & fault tolerance |
| **Edge Locations** | Intermediate sites (used by CloudFront, Global Accelerator) to reduce latency |

```
Region → contains multiple → Availability Zones → contains → Data Centers
```

---

## 💰 Key Benefits

| Benefit | Description |
|---|---|
| **Metered Billing** | "Pay-as-you-go" — only pay for what you use, no long-term contracts |
| **Global Infrastructure** | Regions + AZs ensure high availability and fault tolerance |
| **Shared Responsibility Model** | AWS secures the cloud (hardware); you secure what's *in* the cloud (data, code, config) |
