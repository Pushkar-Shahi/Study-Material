## ☁️ The Core Definition

**Cloud computing** is using a network of remote servers hosted on the internet to store, manage, and process data — instead of a local server or personal computer.

| Who | Responsibility |
|---|---|
| **Provider** (e.g., AWS) | Owns the hardware, manages real estate and IT staff |
| **You** | Configure services and code |

> 💡 "Cloud" is a broad term covering many categories: **compute, storage, databases, and networking.**

---

## 🕰️ Evolution of Cloud Hosting

Cloud hosting has evolved through several distinct phases since **1995**.

| Era | Model | Description | Trade-off |
|---|---|---|---|
| **1995** | 🖥️ Dedicated Servers | One physical machine per business | Secure but expensive, manual maintenance |
| — | 🧩 Virtual Private Servers (VPS) | Virtualization splits one machine into "sub-machines" | Better utilization + isolation |
| **Mid-2000s** | 🏘️ Shared Hosting | Hundreds of businesses share one machine | Cheap, but limited functionality & poor isolation |
| — | ☁️ Cloud Hosting | Distributed computing — many machines act as one system | High flexibility, scalability, security at low cost |
| **Modern** | 📦 Containers & 🔧 Serverless | OS-level app isolation → provider manages all infrastructure | You only manage your code |

```
Dedicated Servers → VPS → Shared Hosting → Cloud Hosting → Containers → Serverless
```
